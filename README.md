## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). The page reloads when you edit files.

## Deploy

```bash
npm run deploy
```

This builds the app and publishes the `gh-pages` branch used by [https://amiraliesi83.github.io/Portfolio/](https://amiraliesi83.github.io/Portfolio/).
